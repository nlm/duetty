# poly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go terminal app that listens to a shared microphone and shows every utterance (or typed sentence) in two side-by-side panes, original and translation, for two configured languages.

**Architecture:** Mic PCM (48 kHz s16le mono) → optional ONNX denoiser → talktome's VAD `Listener` (Silero + Smart Turn) → Silero-based trim → `stt.Resolver` (Whisper auto-detect, forced-pair fallback, lingua text check, noise floor) → `translate.Translator` (chat completions) → `convo.Log` (ordered rows, cancel) → tview two-pane UI. Audio/VAD packages are copied from `~/llmchat/talktome/internal/*` and import-rewritten; everything new is small packages under `internal/`.

**Tech Stack:** Go 1.26, tview/tcell, malgo (mic), onnxruntime_go (Silero, Smart Turn, denoiser), `github.com/pemistahl/lingua-go`, `github.com/BurntSushi/toml` (as talktome), `github.com/mattn/go-runewidth`.

**Spec:** `docs/superpowers/specs/2026-11-07-duetty-design.md`

## Global Constraints

- Module `github.com/nlm/poly`, binary `poly`, repo root `/root/poly`.
- Copy talktome packages, do not import `github.com/nlm/talktome`.
- No conversation text (transcripts, translations, typed input) is ever written to disk or to any log. Logs hold timings, states, errors only.
- No speaker audio / TTS code at all (drop `Speaker`, `PlayStream`, `Beep`, notify when copying `audioio`).
- No energy VAD: Silero only (`audiolevel` may be copied only if `vad`/`silerovad` need it to compile; it is never selectable).
- Defaults: `languages = ["fr","en"]`, `stt_model = "whisper-large-v3"`, `translate_model = "mistral-small-3.2-24b-instruct-2506"`, `translate_context = 4`, `timestamps = false`, `silero_vad_threshold = 0.6`, `vad_min_speech_ms = 250`, trim margin 150 ms, `smart_turn = true`, `denoise = false`.
- Silero/Smart Turn/denoise model missing → warn and continue (Smart Turn → fixed silence; denoise → off). Silero missing is fatal (no energy fallback exists).
- Endpoint: OpenAI-compatible base URL; key from `OPENAI_API_KEY` env or config. Test endpoint: `https://api.scaleway.ai/<default_project_id>/v1`, key = `secret_key` in `~/llm-benchmark-creds.yaml`. Never print, log or commit the key.
- onnxruntime lib for dev: `~/llmchat/talktome/third_party/onnxruntime/lib/libonnxruntime.so.1.27.0` (config `onnxruntime_lib`).
- Models for dev: `~/llmchat/talktome/models/silero_vad.onnx`, `~/llmchat/talktome/models/smart-turn/smart-turn-v3.2-cpu.onnx`.

## Review Focus

1. **API down, 401, timeout, or 5xx mid-conversation** → that utterance gets an error row ("transcription failed" / "translation failed") and listening continues; never a crash or hang. Test in Task 7.
2. **Utterances overlapping and finishing out of order** (a long sentence still transcribing when a short one finishes) → rows appear in capture order; a late row is inserted above newer ones, not appended. Test in Task 7.
3. **A response arriving after Escape** → the cancelled row stays "cancelled"; a late transcript/translation must not overwrite it. Test in Task 7.
4. **Japanese/CJK double-width text and narrow terminals** → pane wrapping and row alignment use display width, not rune count; both halves of a row start on the same line. Test in Task 8.
5. **A language pair lingua doesn't support, or typed text lingua can't decide** → text check is skipped and the logprob/auto result stands; typed text defaults to the first language with the result still shown. Tests in Tasks 4 and 5.

### Task 5: Resolver (language choice + noise floor)

**Files:**
- Create: `internal/stt/resolve.go`, `internal/stt/resolve_test.go`

**Interfaces:**
- Consumes: `Transcriber`, `*langid.Identifier`.
- Produces:
  ```go
  var ErrNoise = errors.New("noise")
  type Resolved struct{ Lang, Text string }
  type Resolver struct {
      T Transcriber; ID *langid.Identifier; Pair [2]string
      LogprobFloor, MaxCompression float64
  }
  func (r *Resolver) Resolve(ctx context.Context, wav16k []byte) (Resolved, error)
  // DetectTyped picks the language of typed text; falls back to Pair[0].
  func (r *Resolver) DetectTyped(text string) string
  ```
- Algorithm (from the spec, finding 2):
  ```
  a := T.Transcribe(wav, "")
  if a.Language ∈ Pair:
      if ID.Detect(a.Text) == (other, true): b := T.Transcribe(wav, other); return check(b, other)
      return check(a, a.Language)
  // outside the pair: two forced passes in parallel
  x, y := T.Transcribe(wav, Pair[0]) ‖ T.Transcribe(wav, Pair[1])
  // a forced pass whose text is clearly in the OTHER pair language echoes the original
  if ID.Detect(x.Text) == (Pair[1], true): return check(y or x-as-text, Pair[1])  -> use y if it succeeded, else x.Text labelled Pair[1]
  if ID.Detect(y.Text) == (Pair[0], true): symmetric
  else pick higher AvgLogprob
  check(res, lang): trimmed text empty, AvgLogprob < LogprobFloor, or CompressionRatio > MaxCompression → ErrNoise
  ```
  One forced pass failing → use the other. All calls failing → return the last error (not ErrNoise).

### Task 7: Translator and conversation log (pipeline core)

**Files:**

**Interfaces:**
- Produces:
  ```go
  // translate
  type Pair struct{ Lang, Original, Translation string } // a past row, for context
  type Translator interface {
      Translate(ctx context.Context, text, from, to string, history []Pair) (string, error)
  }
  type Client struct{}
  func NewClient(baseURL, apiKey, model string) *Client

  // convo
  type Status int // Pending (hidden), Original (translation in flight), Done, Cancelled, Failed
  type Row struct {
      Seq       uint64    // capture order
      At        time.Time // capture time (for -timestamps)
      Status    Status
      Lang      string    // source language
      Original, Translation string
      Err       string    // short, user-facing, no secrets
  }
  type Log struct{ /* mutex, rows sorted by Seq, cancel funcs */ }
  func New(pair [2]string, r Resolver, tr translate.Translator, contextN int, onChange func()) *Log
  type Resolver interface { // satisfied by *stt.Resolver
      Resolve(ctx context.Context, wav16k []byte) (stt.Resolved, error)
      DetectTyped(text string) string
  }
  func (l *Log) SubmitAudio(wav16k []byte)  // async; Seq assigned now
  func (l *Log) SubmitText(text string)     // async; ignores blank text
  func (l *Log) CancelPending()             // Esc
  func (l *Log) Rows() []Row                // visible rows (Status != Pending), Seq order, copy
  func (l *Log) InFlight() int              // for the status bar
  ```
- Translation request: `POST {base}/chat/completions`, `temperature: 0`, system: `"You translate from {FromName} to {ToName}. Output only the translation of the last user message, nothing else. No quotes, no notes."`, then the last `contextN` rows as alternating user (original) / assistant (translation in `to` language, using the original if the row's source was `to`) messages, then the user text. Strip surrounding whitespace/quotes from the reply.
- Error strings shown in rows: `"transcription failed: <status or 'timeout'>"`, `"translation failed: …"`. Each request has a 30 s timeout.
- `ErrNoise` → row is removed silently (it was never visible). A cancelled row that was still Pending is removed too (never visible); a visible one becomes `Cancelled`. Results arriving for a Cancelled row are dropped.
- History for context: last `contextN` rows with Status Done, excluding the current row.

**Interfaces:**
- Consumes: `convo.Row`, `config.LanguageName`.
- Produces:
  ```go
  // Layout renders rows into two equal-height columns of tview-tagged lines.
  func Layout(rows []convo.Row, pair [2]string, width int, timestamps bool) (left, right []string)
  type App struct{}
  func New(pair [2]string, model string, timestamps bool) *App
  func (a *App) SetRows(rows []convo.Row)             // thread-safe, QueueUpdateDraw
  func (a *App) SetStatus(level float64, state string, inFlight int, muted bool)
  ```

- Rendering rules: column width = `(width-1)/2` minus border; wrap by display width (`go-runewidth`), breaking CJK anywhere and Latin at spaces; each row pads the shorter side with blank lines so both are equal height; one blank line between rows. Source side prefixed `» ` and bright (`[white::b]`), other side prefixed `  ` and soft (`[gray]`); continuation lines indented 2 cells. Translation pending → `…translating` (dim italic). Cancelled → both sides dim, other side `cancelled`. Failed → other side `[red]` + `Err`. With timestamps, prefix the first line `HH:MM ` on both sides. Escape any `[` in user text (`tview.Escape`).
- Screen: header row per pane with `LanguageName` (left = pair[0]); both panes in one `tview.Flex` and scrolled together (single scroll offset applied to both; auto-follow bottom unless user scrolled up); status bar: 8-cell level meter, state (`listening`/`hearing`/`muted`), `transcribing (n)` when n>0, `fr ⇄ en`, model name; input line at bottom. Keys: Enter submit, Esc cancel, Ctrl+P mute, PgUp/PgDn + wheel scroll, Ctrl+C quit, `?` help when input empty.
